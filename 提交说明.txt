三、作品概述
以「暗黑极客风 + 霓虹绿点缀」为主视觉的单文件 HTML 简历，包含 8 大板块：
关于我 / 技能档案 / 证书集 / 重点项目 / 视觉追焦 / AI 实战 / 蓝图工坊 / 联系方式。

核心亮点：
1. 18 项官方认证证书墙：分类筛选 + 缩略图 + Lightbox 原图查看 + 防伪编号一键复制；
2. AI 蓝图工坊：本地蓝图引擎，输入创意离线秒出 MVP 架构方案（无需任何 API）；
3. AI 对话分身：本地知识库问答，以本人口吻介绍院校、项目与技能；
4. 丰富动效：WebGL 着色器背景、Canvas 礼花粒子、打字机、目光追踪、滚动视差；
5. 背景音乐自动播放，支持手动暂停/续播；
6. 响应式设计：桌面端横排导航 / 移动端横滑导航，自适应布局。

四、技术栈
HTML5 + Tailwind CSS + 原生 JavaScript + Canvas 2D/WebGL + Font Awesome 6
部署：GitHub Pages

五、本地运行方式
无需构建，浏览器直接打开 index.html 即可；
或在该目录执行 python -m http.server 8000 后访问 http://localhost:8000
